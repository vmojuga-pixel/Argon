# Unicorn Portfolio — Part 1 (Architecture)

## Multi-Engine Portfolio Pattern
6 parallel B2B DeepTech verticals dalam satu dashboard:
1. Islamic FinTech (Sukuk/Murabahah) — TRX ↔ Riyadh/Dubai
2. AI Data Center (PUE cooling + BESS arbitrage) — JS-SEZ Johor
3. Semiconductor AOI (2.5D/3D chiplet defect) — Penang/Kulim
4. B2B e-Invoicing (LHDN MyInvois + FX) — MY/SG/ID/TH
5. Agri-Climate (EUDR palm oil + carbon CBAM) — Johor/Sabah/Sarawak
6. OT/SCADA Cyber (Cyber Security Act 2024) — Putrajaya/PTP/Grid

## Engine Registry Pattern
Setiap engine object: id, code, name, subtitle, hub, tamUsdB, baseArrUsdM,
valuationMultiple, grossMarginPct, color, badge.
State scalable via `scaleMultiplier` (1x Day-1 seed → 10x sovereign).

## Portfolio Valuation Calculator
scaledArr = baseArrUsdM * scaleMultiplier
valuation = scaledArr * valuationMultiple
isUnicorn = valuation >= 1000 (USD M)
totalArr = sum all engines
totalValuation = sum valuations
