# Unicorn Portfolio — Part 3 (Runtime State)

## Cryptographic Merkle State Hash
Setiap tick auto-scaler: computeSHA256(`NUSANTARA6-${pods}-${rps}-${Date.now()}`)
Display first 8 + last 8 chars as `0x{...}...{...}`.
Tamper-proof state signature untuk audit trail.

## Real-Time Telemetry Sync
- FX: fetch exchangerate-api.com/v4/latest/USD → rates.MYR
- METOC: open-meteo.com?latitude=1.4556&longitude=103.5906 → temp + windspeed
Update clusterTelemetry + dcParams (ambientTempC) on mount.
Fallback: static defaults if fetch fail (no crash).

## Auto-Scaler Heartbeat Loop
setInterval 2600ms:
- targetPods = 420 * scaleMultiplier + random(0, 65)
- targetRps = 54000 * scaleMultiplier + random(0, 4200)
- p99Latency = 1.6 + random(0, 0.6)
Kill-switch check before tick. Cleanup on unmount.

## Audit Log Pattern
Ring buffer (max 36 entries). Each: { id, time, engine, msg }.
Prepend on new event, slice(0, 35) to cap.
Display: [time] [engine] msg dengan monospace truncate.
