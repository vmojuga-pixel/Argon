# Unicorn Portfolio — Part 4 (Router + Catalog)

## Regex Intent Router (Voice + CLI)
Pattern match command → route to tab:
- /unicorn|scale 10|maksimum/ → scaleMultiplier = 6.5
- /sukuk|islamik/ → TAQWA_LIQUID tab
- /data center|cooling|johor/ → THERMA_GRID tab
- /semiconductor|wafer|penang/ → SILICON_EYE tab
- /invois|lhdn|asean|fx/ → ASEAN_CLEAR tab
- /palm|sawit|eudr|carbon/ → VERI_PALM tab
- /cyber|scada|ncii/ → AEGIS_NCII tab
- /geran|grant|pitch|khazanah/ → INVESTOR_PITCH tab
Fallback: LLM synthesis for freeform query.

## Web Speech API Pattern
Recognition: SpeechRecognition || webkitSpeechRecognition
continuous=false, interimResults=false, lang='en-US'.
onstart/onend/onerror toggle isListening state.
onresult → handleCommandSubmit(transcript, 'VOICE').
Synthesis: SpeechSynthesisUtterance, rate=1.04, pitch=0.95.
Cancel previous before new speak. Skip if kill-switch / voice disabled.
