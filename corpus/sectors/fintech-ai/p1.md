# FinTech AI — Part 1

## 1. SAP LangChain ReAct Agent
Enterprise agent guna SAP OrchestrationClient + LangChain ReAct.
Tools: ERP inventory, M365 Teams message, SharePoint RAG search.
Pattern: LLM -> Thought -> Action -> Observation loop, max_iterations=5.
Reference: langchain.agents.create_react_agent + AgentExecutor.

## 2. React Native FlatList Optimizer
High-performance long-list virtualization (10k+ rows @ 60fps).
Key props: getItemLayout, removeClippedSubviews, initialNumToRender=10,
maxToRenderPerBatch=10, windowSize=5.
For variable height: use CellRendererComponent. For 100k+ use @shopify/flash-list.

## 3. Invoice Extraction JSON Schema
Schema fields: document_type, fields{invoice_number,vendor_name,amount,currency},
overall_confidence (0-1), per_field_confidence, status enum
[success,partial,failed,human_review_required].
Validate: total_amount == sum(line_items.amount).
