# FinTech AI — Part 3 (Security + IDP)

## 7. fastapi-fortify WAF Config
Middleware blocks SQLi/XSS/path-traversal/command-injection + bot detection.
rate_limit_requests=100, rate_limit_window=3600.
Bench: 96.4% coverage, 42.3ms avg, 1247 RPS, 156MB, 100% security pass.
Alternatives: fastapi-guard (20+ per-route decorators),
defensio (NoSQLi + HTTP Desync protection).

## 8. py-idp 6-Stage Pipeline
Stages: parse -> classify -> extract -> assess -> validate -> HITL.
Backend: openai/ollama/anthropic/gemini (12+ LLM).
Schema-driven (Pydantic), business_rules list, auto-chunking, self-hosted OCR.
Bench (Ollama qwen2.5:0.5b): schema-valid 100%, Field F1 0.96,
precision 1.00, recall 0.93, latency 2.05s/doc.

## 9. ext_data Hybrid (spaCy + GLiNER)
Lightweight doc extraction tanpa LLM.
Formats: PDF, DOCX, PPTX, PNG, JPG.
OCR via Tesseract. Automatic classification + line item extraction.
