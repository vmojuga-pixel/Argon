# FinTech AI — Part 4 (Rate Limit + GPU)

## 10. throttled / Throtty Rate Limiting
Redis-backed distributed rate limiter for FastAPI.
Strategies: sliding-window counter, sliding-window log, token bucket, fixed window.
Rules: "10/60" (10 req per 60s), "10/60;100/3600" (burst + sustained).
Rate by: IP, user ID, API key, custom logic.
Redis required for multi-server deployments.

## 11. GPU Monitor Service
Daemon/cron job querying nvidia-smi via subprocess.
Fields: index, name, temperature.gpu, utilization.gpu, memory.used, memory.total.
Thresholds: TEMP_WARN=80C, TEMP_CRIT=85C, UTIL_IDLE=5%.
Alerting: Slack/PagerDuty when status != HEALTHY.
Cost warning when GPUs idle (over-provisioning detection).
Deploy: systemd service / Docker sidecar / cron every 60s.
