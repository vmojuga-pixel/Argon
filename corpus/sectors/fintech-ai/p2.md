# FinTech AI — Part 2 (Data Quality)

## 4. Airflow ETL DAG with DQ Gates
3-file structure: etl_pipeline_dag.py -> dw_population_utils.py -> data_quality_checks.py.
Stages: extract -> dq_raw -> transform -> dq_clean -> load.
Each DQ gate fails pipeline if validation fails.
Retries=2, retry_delay=5min, email_on_failure=True.
Deploy: docker compose (airflow-webserver, scheduler, postgres, redis).

## 5. Great Expectations Validator
Declarative ExpectationSuite checks: not_null, unique, between, in_set.
Works with Pandas, Spark, SQL, BigQuery.
Checkpoint run + fail pipeline if not success.

## 6. Pandera Schema Validator
Lightweight pandas-native schema-as-code.
Column types + Check.greater_than_or_equal / isin / str_length.
Decorator style: @pa.check_types on functions returning DataFrames.
Standalone: schema.validate(df) raises SchemaError.
